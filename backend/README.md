# Бэкенд

Базовое API текстовых заметок на FastAPI и SQLite. Поддерживает создание,
список с пагинацией, просмотр, редактирование и удаление заметок.
Исходный текст сохраняется отдельно от редактируемого.

## Запуск

Требуется Python 3.11 или новее. Команды выполняются из корня репозитория:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -e './backend[dev]'
.venv/bin/python -m uvicorn app.main:app --reload --host 127.0.0.1
```

Интерактивная документация: http://127.0.0.1:8000/docs.
Проверка доступности: `GET /api/v1/health`.

База автоматически создаётся в `backend/data/notes.sqlite3` при первом
запуске. Другую папку можно задать переменной окружения `NOTE_AGENT_DATA_DIR`.
Данные сохраняются между перезапусками.

## API заметок

| Метод | Адрес | Назначение |
|---|---|---|
| POST | `/api/v1/notes` | Создание текстовой заметки |
| GET | `/api/v1/notes?limit=20&offset=0` | Список заметок |
| GET | `/api/v1/notes/{id}` | Полная заметка |
| PATCH | `/api/v1/notes/{id}` | Изменение заголовка или текста |
| DELETE | `/api/v1/notes/{id}` | Удаление заметки и её источника |

Пример тела запроса при создании:

```json
{
  "source_type": "text",
  "title": "Конспект",
  "text": "Текст заметки"
}
```

При редактировании передаётся `expected_version` — значение `content_version`
из полученной заметки, а также `title` и/или `extracted_text`. Если версия
уже изменилась, API возвращает `409`. Исходный текст остаётся в
`source.original_text`.

Поддерживаются только текстовые заметки. Их `ingestion_status` всегда
`ready`, а `enrichment_status` — `not_requested`. Импорт файлов, обработка
ссылок, фоновые задания и интеграция с LLM относятся к следующим этапам.
Удаление пока физическое: удаляются заметка и исходный текст.

Таблицы создаются автоматически; обновление существующей схемы пока
не реализовано. Перед первым изменением схемы потребуется добавить миграции.

## Проверка

```sh
.venv/bin/python -m pytest -c backend/pyproject.toml backend/tests
```

Тесты используют отдельные временные базы и не затрагивают заметки приложения.
