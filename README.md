# Local Note Agent

Локальное приложение для заметок и личной базы знаний с использованием языковых моделей. Помогает собирать материалы из разных источников, находить информацию по смыслу и получать ответы на вопросы по сохранённым заметкам.

Планируемые возможности:

- Создание заметок из текста, веб-страниц, изображений и аудио.
- Извлечение текста, распознавание изображений и расшифровка аудио.
- Автоматическое формирование краткого содержания, тегов и категорий.
- Семантический поиск и чат по базе знаний с указанием источников.
- Интерактивный граф связей между заметками.

Хранение данных и работа моделей выполняются локально. Для загрузки веб-страниц по ссылкам требуется доступ к интернету.

Проект находится на стадии разработки. Основной стек: Python, FastAPI, SQLite, Qdrant, React и TypeScript.
