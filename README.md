# Local Note Agent

Локальное приложение для заметок и личной базы знаний с использованием языковых моделей. Помогает собирать материалы из разных источников, находить информацию по смыслу и получать ответы на вопросы по сохранённым заметкам.

Планируемые возможности:

- Создание заметок из текста, TXT/Markdown и аудио через Telegram и веб.
- Пакетная загрузка, подборки и расшифровка голоса Telegram OGG/Opus.
- Автоматическое формирование краткого содержания, тегов и категорий.
- Гибридный поиск и обычные ответы по базе знаний без цитирования.
- Автоматический граф близких заметок без ручной разметки.

Хранение данных выполняется в развёрнутом приложении. Модели подключаются
через сменяемые адаптеры: локально, на GPU-сервере или в облаке. Для загрузки веб-страниц по ссылкам требуется доступ к интернету.

Сегменты и таймкоды аудио, ссылки на фрагменты и разметка источников ответа
не входят в MVP. PDF, OCR и HTML-ссылки — дополнительные адаптеры.

В репозитории есть прототип импорта на SQLite/SQLAlchemy, который адаптируется
под целевой стек. Первый этап — локальные эксперименты P01–P04, до большой
переработки backend.

Проект находится на стадии разработки. Основной стек: Python, FastAPI, PostgreSQL с pgvector, React и TypeScript.
