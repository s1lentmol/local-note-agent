# Исходный план проекта

Первоначальные технические предложения сохранены в истории Git.
Этот файл не задаёт требований к текущей реализации.

Актуальные документы:

- [Архитектура и границы MVP](architecture.md).
- [План реализации и состояние задач](work-plan.md).
- [Организация работы](team_distribution.md).

Реализация использует PostgreSQL/pgvector и явный SQL через Psycopg.
MVP возвращает обычные ответы по базе; цитирование, источники отдельных
утверждений, аудиосегменты и таймкоды в него не входят.
