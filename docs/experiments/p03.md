# P03: нативное ASR на Apple Silicon

Дата: 2026-11-13. **Ревью P03 пройдено; статус — `review` до интеграции.**
Локальный ASR проверен на публичной русской записи LibriVox длительностью
188,171 секунды с независимым опубликованным контрольным текстом Чехова.
Выполнен реальный ASR
на OGG/Opus, WAV и MP3: полный текст, язык `ru`, Metal, 6,795–7,208 s.
Расхождение литературной части с печатным текстом — 0,43–0,85% слов.
Это расхождение с печатным текстом, а не достоверная WER живой речи:
дословная расшифровка исполнения вручную не сверялась. Настоящий файл Telegram
и разговорная речь в P03 не проверены; сквозная проверка реального голосового
остаётся обязательной в T15.
Backend и бот не изменялись; интеграция T07/T15 не выполнялась.

## Воспроизведение

Все команды ниже выполняются из корня репозитория. Нужны установленный
FFmpeg с libopus/libmp3lame, CMake, Apple Command Line Tools, Python 3.9+.
Скачивание исходников и весов требует сети; само распознавание локальное.

```sh
sh experiments/p03/setup.sh
```

Скрипт проверяет SHA256 архива и модели. Исходники, сборка и веса остаются
в игнорируемом `experiments/p03/local/`. Несовпадение checksum — ошибка,
не автоматическая замена версии. При оборванном скачивании следует отдельно
убрать только неполный файл и повторить установку.

Повтор короткого синтетического smoke-теста (macOS voice Milena):

```sh
say -v Milena -r 155 -f experiments/p03/smoke.txt \
  -o experiments/p03/local/smoke.wav --file-format=WAVE --data-format=LEI16@16000
python3 experiments/p03/prepare.py experiments/p03/local/smoke.wav
python3 experiments/p03/probe.py \
  experiments/p03/local/audio/voice.ogg \
  experiments/p03/local/audio/voice.wav \
  experiments/p03/local/audio/voice.mp3 \
  --reference experiments/p03/smoke.txt --smoke
```

`prepare.py` делает OGG/Opus mono 48 kHz, 32 kbit/s, application=voip и
MP3 96 kbit/s из PCM. Это лишь кодирование, характерное для голосовых,
а не файл, прошедший Telegram. При исходном Telegram OGG/Opus скрипт копирует
его без перекодирования; WAV/MP3 производятся из декодированного оригинала.
Оригинал хранить отдельно от генерируемого `local/audio/`.

Python-контракт в `experiments/p03/probe.py`:

```python
from pathlib import Path
from probe import transcribe

result = transcribe(
    Path("local/original.ogg"),
    Path("local/build/bin/whisper-cli"),
    Path("local/ggml-large-v3-turbo-q5_0.bin"),
)
# {"text": "полный текст", "language": "ru"}
```

Пути примера относятся к каталогу `experiments/p03`. Язык извлекается из
сообщения автоопределения pinned CLI, а не подставляется как `ru`.
Смена версии CLI может потребовать обновления парсера.
При пустом тексте/отсутствии языка вызов завершается ошибкой. CLI запускается
без JSON/SRT/VTT output. Внутреннее выравнивание Whisper включено: префиксы
таймкодов stdout удаляются регулярным выражением в памяти до возврата результата.
Полный текст возвращается одним полем, stderr обрабатывается в памяти.
Сегменты и таймкоды не сохраняются. Отключать внутреннее выравнивание через
`-nt` нельзя: на длинном исходнике обнаружены пропуски, см. ниже.
Временный PCM удаляется после вызова. Timeout subprocess — 600 секунд.

## Исторический короткий smoke (до проверки длинной записи)

Контрольный текст: [smoke.txt](../../experiments/p03/smoke.txt), 42 слова.
Это публичный искусственный текст без личных данных, озвученный Milena.
В этом раннем прогоне использовался `-nt`; финальный код его больше не задаёт.
Повтор команд выше текущим кодом не обязан воспроизводить эти старые числа.
Результаты последнего прогона: [smoke-results.json](../../experiments/p03/smoke-results.json).
Каждый формат запускался в отдельном процессе, последовательно. Metal shader
cache уже прогрет; это не измерение холодного старта и не постоянный сервис.

| Вход (все 18,363 s) | Язык | Декодирование, s | ASR, s | Всего, s | RTF ASR | max RSS, bytes |
|---|---|---:|---:|---:|---:|---:|
| OGG/Opus | ru | 0,063 | 1,379 | 1,442 | 0,075 | 881033216 |
| WAV PCM | ru | 0,042 | 1,377 | 1,424 | 0,075 | 881934336 |
| MP3 | ru | 0,041 | 1,376 | 1,417 | 0,075 | 883326976 |

ASR время включает запуск процесса, загрузку модели, определение языка и
распознавание; декодирование показано отдельно. SHA256 модели вычисляется
после замеров и не включён во время. RSS из `/usr/bin/time -l` относится
к процессу CLI; это не полная оценка GPU/unified memory. Не экстраполировать
короткий прогон на 2–5 минут. Все три запуска подтвердили строку
`whisper_backend_init_gpu: using MTL0 backend`; отдельная диагностика также
показала `ggml_metal_init: found device: Apple M4 Pro`.

Полный транскрипт одинаков для всех трёх форматов:

> Сегодня мы проверяем локальное распознавание русской речи на компьютере. Голосовая заметка должна превратиться в полный текст. Исходную запись нужно сохранить отдельно. В пятницу в 15 часов мы обсудим результаты эксперимента, проверим ошибки и сравним три формата ОХК, ВАВ и МП-3.

Текст читаем, основные предложения сохранены. Заметные отличия:

- «огг» → «ОХК»: ошибка распознавания названия формата.
- «пятнадцать» → «15»: смысл сохранён, изменена запись числа.
- «вав» → «ВАВ», «эм пэ три» → «МП-3»: нормализация аббревиатур, последняя неточна.
- Двоеточие перед перечнем потеряно.

Простая WER = 5/42 = 11,90% во всех форматах. Метод: lowercase,
`ё` → `е`, токены `\w+`, расстояние Левенштейна по словам; числа и
аббревиатуры не нормализуются. Поэтому WER учитывает и смену записи числа;
это не оценка доли смысловых ошибок. Результат синтетического голоса нельзя
переносить на живую речь, паузы, шум, имена и длинные записи.

Исходник:

Контроль — [печатный текст Чехова, Библиотека Комарова](https://ilibrary.ru/text/438/p.1/index.html),

особенность произнесения. Поведение на шумной спонтанной речи не проверено.

### Найденное ограничение `-nt` и исправление

Первый прогон использовал ранние параметры с `-nt` и заметно потерял текст.
[Метрики исходного прогона](../../experiments/p03/public-no-timestamps-metrics.json):
OGG — 69/234 = 29,49%, WAV — 54/234 = 23,08%, MP3 — 66/234 = 28,21%.
Например, пропадал блок про карикатуру и приглашение за город; реплика
«Разве преподавателям гимназии и женщинам…» повторялась.

В pinned исходниках `examples/cli/cli.cpp` флаг `-nt` устанавливает одновременно
`wparams.print_timestamps=false` и `wparams.no_timestamps=true`.
Таким образом он меняет и внутренний режим декодирования, а не только печать.
В финальном `probe.py` флаг убран; префиксы временных меток удаляются в памяти
из stdout до сохранения результата. На том же исходнике, модели и остальных
параметрах это устранило крупные пропуски. Это наблюдение на одной записи,
не утверждение об универсальной причине всех ошибок Whisper.

Сегменты, интервалы и ASR JSON не записываются ни в финальные артефакты,
ни в локальные результаты данного прогона. Из stdout извлекается только текст.
Публичные финальные артефакты проверены на отсутствие временных префиксов.
